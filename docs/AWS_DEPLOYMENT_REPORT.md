# AWS EKS Cloud Deployment Strategy & Verification Report

## Executive Summary

This report documents the cloud deployment design, manifest overlay architecture, and verification strategy for hosting **Q-Validate** on **Amazon Elastic Kubernetes Service (AWS EKS)**.

---

## ☁️ Deployment Environment Specifications

| Parameter | AWS EKS Target Configuration | Local Kubernetes Reference |
|---|---|---|
| **Cloud Provider** | Amazon Web Services (AWS) | Docker Desktop Kubernetes |
| **Kubernetes Version** | `v1.36` (EKS Managed) | `v1.36.1` |
| **Cluster Name** | `qvalidate-eks-cluster` | `docker-desktop` |
| **Region** | `us-west-2` (US West - Oregon) | `localhost` |
| **Node Group** | 3x Managed `t3.medium` instances | 1x Local Node |
| **Container Registry** | Amazon ECR (4 Repositories) | Local Containerd Engine |
| **Ingress Controller** | AWS Application Load Balancer (ALB) | NGINX / Local Ingress |
